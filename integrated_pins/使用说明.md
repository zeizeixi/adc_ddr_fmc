# 合并引脚约束使用说明

文件：top_pins_integrated.xdc。此文件合并引脚分配，并在每行末尾加入中文备注；备注使用 Tcl 的 `; #` 分隔。

## 包含内容

- 系统时钟 R4、复位 U7 及原厂家 sys_clk 时钟定义/路由设置。
- 全部 70 个 DDR 端口的 PACKAGE_PIN 和 IOSTANDARD，按当前厂家工程所引用 MIG 的生成约束原值提取。
- ADC 34 个端口的原接线球脚；Bank14/15/16 按现有电源图设置 LVCMOS33。Bank34 电平未猜填。
- 39 个未来 FMC 端口的映射，全部注释，避免当前顶层没有相应端口时报错。D0=P20，D5=AB18、D6=AA18、D11=W21、D15=W22 已采用更正后的表。
- 不包含 LED 分配，顶层应使用此前无 LED 副本。

## 如何加入工程

Add Sources → Add or Create Constraints → 添加 top_pins_integrated.xdc，并勾选 Copy constraints into project。

工作工程中旧 top.xdc 和旧 ADC 引脚示例不要与本文件重复启用，尤其不能重复创建 sys_clk 时钟或残留 led 端口约束。不要删除/禁用 MIG IP 自带 XDC；其内部时序、SLEW、IN_TERM、IO_BUFFER_TYPE 等仍由 IP 管理。本文件的 DDR 球脚/电平是对相同配置的显式重申，不是 MIG 自带 XDC 的替代品。

runtime_cdc.xdc 也继续单独保留，仍按之前要求仅用于实现、PROCESSING_ORDER=LATE。本次只合并板级引脚，没有把依赖综合网表的 CDC 约束提前混入引脚文件。

## 当前边界

本文件是真正的 .xdc 文件，但仍是“未飞线原接线核对版”，不是可直接生成 bitstream 的最终约束。ADC Bank34 电平、输入采样时钟输出端 P/N 反接，以及 G18/L21 普通 IO 作为时钟输入的问题仍待解决。ADC 输入时钟及 input_delay 未编造，不能凭本文件宣称时序已收敛。

验证：DDR 的 70 个端口均提取到了厂家 PACKAGE_PIN/IOSTANDARD；包括注释中的 FMC 在内，145 个球脚条目无重复。未运行整工程实现或上板验证，也没有修改现有工程或厂家参考文件。

厂家来源：./local_inputs/mig_7series_0.xdc。

这一路径仅用于记录来源，合并文件没有 source/import 外部文件的命令，因此以后搬移交付文件不依赖该目录。
